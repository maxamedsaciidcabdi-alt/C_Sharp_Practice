# Beginner C# File Handling

## Design

Create these controls on `Form1`:

| Control | Name | Text |
|---|---|---|
| Button | `btnCreateFile` | Create File |
| Button | `btnReadLines` | Read File (ReadLines) |
| Button | `btnDeleteFile` | Delete File |
| Button | `btnClearContents` | Clear File Contents |
| ListBox | `lstFileContents` | Leave blank |

Set the form title to `C# File Handling`.

## Complete code

Add `using System.IO;` at the top of `Form1.cs`. Keep the constructor and `InitializeComponent()` generated by Visual Studio. Add the methods below inside the `Form1` class.

```csharp
using System.IO;
using System.Windows.Forms;

// 1. Create the file
private void btnCreateFile_Click(object sender, EventArgs e)
{
    // Create Home.doc for writing
    StreamWriter outputfile;
    outputfile = File.CreateText("Home.doc");

    // Write text and close the file
    outputfile.WriteLine("Hello from C#!");
    outputfile.WriteLine("This is my text file.");
    outputfile.Close();

    MessageBox.Show("File created.");
}

// 2. Read using ReadLines()
private void btnReadLines_Click(object sender, EventArgs e)
{
    // Check whether the file exists
    if (!File.Exists("Home.doc"))
    {
        MessageBox.Show("Create the file first.");
        return;
    }

    // Show each line in the ListBox
    lstFileContents.Items.Clear();

    foreach (string line in File.ReadLines("Home.doc"))
    {
        lstFileContents.Items.Add(line);
    }
}

// 3. Delete the file
private void btnDeleteFile_Click(object sender, EventArgs e)
{
    // Check whether the file exists
    if (!File.Exists("Home.doc"))
    {
        MessageBox.Show("File not found.");
        return;
    }

    // Delete the file
    File.Delete("Home.doc");
    lstFileContents.Items.Clear();

    MessageBox.Show("File deleted.");
}

// 4. Clear the file contents
private void btnClearContents_Click(object sender, EventArgs e)
{
    // Check whether the file exists
    if (!File.Exists("Home.doc"))
    {
        MessageBox.Show("File not found.");
        return;
    }

    // Keep the file but remove its text
    File.WriteAllText("Home.doc", string.Empty);
    lstFileContents.Items.Clear();

    MessageBox.Show("File contents cleared.");
}
```

## How it works

- **Create File:** `File.CreateText("Home.doc")` creates the file and returns a `StreamWriter`. `WriteLine()` writes text; `Close()` closes the writer.
- **Read File:** `File.ReadLines("Home.doc")` supplies the lines one by one to the `foreach` loop.
- **Delete File:** `File.Delete("Home.doc")` removes the file.
- **Clear File Contents:** `File.WriteAllText("Home.doc", string.Empty)` empties the file but keeps it.

## Important notes

- `StreamWriter` writes text. `StreamReader` reads text.
- Although the filename ends in `.doc`, the content written by this example is plain text, not a formatted Microsoft Word document.
- The relative path `"Home.doc"` means the file is created in the application's current working directory, which can vary when running from Visual Studio.
- Double-click each button in the Designer to create its Click event and connect it to the matching method.
